# Polska Hockey Pool

The family hockey pool's website: standings, team rosters, scoring leaders, the draft board and past seasons.

Live at **https://wlodar41.github.io/polskaHL2627/**

The whole site is one self-contained file, `index.html` (headshots and data are built in). The 2026-27 season shows
mock data until the draft; the History tab (2025-26) is real.
